## ما هو رسين؟

يصل إلى غرف الأخبار وفرق العلاقات العامة كل يوم عشرات الأخبار عن الموضوع نفسه، من الصحف والمواقع ومنصات التواصل. رسين يجمع هذه الأخبار في قصة واحدة، ويتتبّع أول مصدر نشر الخبر بالأدلة، ويفرّق بين الادعاء والمعلومة الموثّقة. وفي النهاية يجهّز موجزًا تكون كل معلومة فيه مربوطة بمصدرها.
## أقسام المنصة

1. **الرصد والفرز الذكي**: جمع الأخبار وتجميع المكرر منها في قصص.
2. **تتبّع المصادر والتحقّق**: أول مصدر للخبر وقرائنه، وحالة التحقق منه.
3. **التغطية والجمهور والسمعة**: حجم التغطية واتجاه الحديث.
4. **تحليل الحملات والمنافسين**: الانتشار غير الطبيعي والحسابات المترابطة.
5. **مؤشرات الأداء والتقارير**: المؤشرات والموجزات الجاهزة للمراجعة.
6. **الاستشراف ودعم القرار**: التنبيه بالقضايا الصاعدة واقتراح الخطوة التالية.

## محتويات المستودع

| المجلد | المحتوى |
|---|---|
| [`raseen-frontend/`](raseen-frontend/) | الموقع والمنصة (HTML). هذا المنشور على الرابط أعلاه |
| [`raseen-backend/`](raseen-backend/) | جمع الأخبار وتحليلها: تجميع القصص، وأول مصدر، والموجز. قاعدة البيانات على Supabase |
| [`raseen-app/`](raseen-app/) | نسخة لوحة التحكم المبنية على Lovable (React) |
| [`.github/workflows/`](.github/workflows/) | نشر الموقع تلقائيًا، وجمع الأخبار كل ساعة |

## كيف يشتغل

- **الموقع**: أي تعديل يُدمج في الفرع `raseen-frontend` يُنشر تلقائيًا على GitHub Pages خلال دقيقة تقريبًا.
- **جمع الأخبار**: يشتغل كل ساعة على GitHub Actions. يقرأ المصادر ويجمع الأخبار المتشابهة في قصص، ويقترح أول مصدر، ثم يكتب موجزًا بمساعدة Groq، ويحفظ النتائج في Supabase.
- **مفاتيح الخدمات** محفوظة في إعدادات المستودع (Actions secrets)، وغير موجودة في الكود.

## تعديل الموقع

مصادر الموقع والمنصة موجودة في `raseen-frontend/src/`. بعد التعديل شغّل:

```sh
cd raseen-frontend/src
python3 build.py
```

التفاصيل في [`raseen-frontend/README.md`](raseen-frontend/README.md)، وطريقة إعداد الباك إند في [`raseen-backend/README.md`](raseen-backend/README.md).
