# رسين Raseen · الواجهات

The frontend prototype for Raseen: the marketing website and the platform, combined into one link. These files are ready to copy into the team's GitHub repository.

## الملفات

| الملف | وش فيه |
|---|---|
| `index.html` | الموقع كامل. «تسجيل الدخول» و«جرّب المنصة» يفتحان المنصة فوقه |
| `platform.html` | المنصة لحالها |
| `concepts/setup-orbit-radar-frontpage.html` | التصورات الثلاثة لشاشة بدء الرصد: المدار والرادار والصفحة الأولى |
| `src/web.src.html` | مصدر الموقع |
| `src/app.src.html` | مصدر المنصة |
| `src/build.py` | يبني `app.html` و`raseen.html` من المصادر (`python3 build.py` داخل `src/`) |
| `assets/` | شعار رسين الجديد (النقطة والموجات): `logo-white` للخلفيات الداكنة و`logo-navy` للفاتحة (SVG وPNG)، والرمز وحده `mark-*`، وأيقونة المتصفح `favicon` |

## شاشات المنصة

1. **تسجيل الدخول** `#login`
2. **مدار الموضوع** `#setup`: تكتب الموضوع، ورسين يرسم ثلاث دوائر حوله:
   - الأسماء اللي بيبحث فيها
   - مواضيع قريبة يقترحها
   - المصادر

   الادعاء المنتشر يظهر كنقطة حمراء.
3. **رادار الرصد** `#scan`: يمسح المصادر ويلتقط الأخبار، ثم «اعرضها» يفتح القصص.
4. **القصص** `#stories`: الأخبار المكررة مجمّعة في قصص.
5. **صفحة القصة** `#story`: المصدر الأول المرشح وقرائنه، وخط الانتشار، ومنحنى التغطية، واعتماد المختص.
6. **الموجز** `#brief`: كل معلومة مربوطة بدليلها `[n]`.
7. **التنبيهات** `#alerts`، **الموجزات** `#briefs`، **المصادر** `#sources`.
8. **الرئيسية** `#home`: ملخص اليوم، قراءة رسين، حجم التغطية، المؤشرات الثمانية، أهم المواضيع والمصادر، الإشارات، ملخص التنبؤ.
9. **التحليل** `#analysis`، **المؤشرات** `#metrics`، **التنبؤ** `#prediction`، **التقارير** `#reports`.
10. **حسابات التواصل** `#social`، **الأدوار والصلاحيات** `#roles`، **الإعدادات** `#settings`.

بيانات الصفحات 8 إلى 10 مأخوذة من تطبيق الفريق على Lovable (البيانات فقط، والتصميم تصميم رسين).

## المكتبات

- GSAP 3.12.2 من cdnjs.
- خلفية الشريط والهيرو بـ WebGL/GLSL مكتوبة يدويًا.
- الموقع يستخدم Three.js r128 وLenis 1.1.13.

## ملاحظات للنقل للمستودع

- البيانات الحالية توضيحية: الشركة «نخلة للاتصالات» افتراضية، وفهم الموضوع في شاشة المدار من قاعدة أمثلة صغيرة.
- عند ربط الباك إند، تُستبدل دالة `kb()` في `app.src.html` باستدعاء API، وكذلك بيانات القصص `S` والرادار `buildRadar()`.
- الشعارات مضمّنة base64 (SVG) داخل `index.html` و`platform.html`. في المصادر هي متغيرات `{{LOGO}}` و`{{LOGO_DARK}}` و`{{FAVICON}}`.
- ألوان الشعار من دليل الهوية: كحلي `#0A2331`، زمردي `#2FB3A3`، ذهبي `#F0B429`.
